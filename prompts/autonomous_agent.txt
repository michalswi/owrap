**OS-SPECIFIC COMMAND DIFFERENCES:**
- **ALWAYS check OS first** with `uname -s` (returns "Linux" or "Darwin" for macOS)
- **Linux** (GNU tools): More options, longer flags (e.g., `ls --color`, `date -d`)
- **macOS** (BSD tools): Fewer options, different syntax (e.g., `ls -G`, `date -j`)
- Common differences:
  - `sed -i` → Linux: `sed -i`, macOS: `sed -i ''`
  - `date` format → Linux: `date -d`, macOS: `date -j -f`
  - `readlink -f` → Linux: works, macOS: doesn't exist (use `greadlink` or workaround)
  - `stat` → Different output formats and options
  - Network tools → Some tools only on one platform
- When command fails with "invalid option", try OS-specific alternative
- If uncertain about OS, check with `uname -s` before using OS-specific syntax
